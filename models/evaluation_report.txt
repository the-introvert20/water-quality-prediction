DECISION THRESHOLD FOR 'POTABLE' (prioritising fewer false Potable predictions)
================================================================================
  Rationale: a false Potable prediction (a sample labelled Not Potable that the model calls
  Potable) is the costlier error for a water-quality screen, so the model is asked to call
  a sample Potable only when its Potable probability is high enough. The threshold is the
  LOWEST value whose out-of-fold Potable precision on TRAINING data is >= 0.70
  (with at least 50 Potable predictions behind the estimate),
  which keeps Potable recall as high as that precision target permits. The 0.70 target is a
  project policy choice, not a scientific or regulatory limit. If a model cannot reach it,
  it keeps its native decision rule. No test label is used to choose any threshold.

  Trade-off: raising the threshold lowers false Potable predictions but raises false Not
  Potable predictions (Potable samples that are rejected), so Potable recall, Macro F1 and
  often accuracy fall. Both errors are reported; neither is free.

================================================================================
LIMITATIONS AND UNCERTAINTY:
================================================================================
1. The features carry weak signal (all absolute correlations with Potability are below 0.04).
   Every model remains close to the majority baseline in accuracy; accuracy alone says little.
2. Results come from one dataset, one train/test split and one nested-CV repetition. The test
   set has 656 records, so test accuracy carries roughly +/-3.7 percentage points of sampling
   uncertainty (see the Wilson intervals above). Fold scores are correlated; SDs over 5 folds
   are rough guides, not confidence intervals.
3. Differences between candidates are small relative to that noise unless the paired test says
   otherwise. Selecting among several candidates and a hyper-parameter grid still carries some
   selection optimism despite the nested design.
4. The threshold target (Potable precision >= 0.70) is a project choice, not a standard. Final
   thresholds were chosen on out-of-fold training predictions using hyper-parameters tuned on
   the same training data, so held-out precision can be lower. Raising the threshold reduces
   false Potable predictions but rejects many samples labelled Potable.
5. Probabilities are model outputs, not calibrated real-world confidence. SVC probabilities are
   Platt-scaled; tree-ensemble probabilities are vote shares.
6. Median imputation fills 14.99% (pH), 23.84% (Sulfate) and 4.95% (Trihalomethanes) missing
   values; tree models and SVC can overfit the imputed values. Scaling is required for SVC and
   Logistic Regression and has no effect on tree splits.
7. There is no external, temporal or geographic validation. Results do not establish scientific,
   medical or production readiness.
